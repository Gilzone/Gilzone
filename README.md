# Hi there, I'm Gilzone 👋

### 🛠️ Hardware Hacker • Edge AI Enthusiast • Embedded Systems Explorer

I build projects that push small, resource-constrained, and discontinued hardware to its absolute limits—from running local LLMs on a $15 Raspberry Pi Zero to turning the abandoned Spotify Car Thing into a 100% standalone, offline gaming console and x86 virtual PC.

---

## 🚀 Featured Open Source Projects

### 🏎️ [Spotify Car Thing — Custom Apps & Standalone OS Suite](https://github.com/Gilzone/carthing-apps)
> **100% On-Device & Offline Webapps, 23 Games, Tools Suite & KolibriOS x86 Emulation**
- Turns the discontinued Spotify Car Thing into an independent, standalone gadget with zero PC or server dependencies.
- Features a 1-Click automated installer, 3D rotary dial coverflow launcher, dial-controlled e-reader, microphone voice memo recorder, and x86 virtualization.

### 🤖 [Running Local LLMs on a $15 Raspberry Pi Zero 2 W](https://github.com/Gilzone/Installing-a-LLM-on-Raspberry-Pi-Zero-2-W)
> **Edge AI & Quantized Inference in 512MB of RAM with Ollama**
- Comprehensive architectural guide and benchmark suite for running SmolLM2 135M and micro-models locally on a $15 single-board computer.
- Kernel swap optimization, frequency tuning, memory budgeting, and REST API setup.

### 💬 [Messager — Real-Time Ephemeral Room Chat](https://github.com/Gilzone/messager)
> **Self-Hosted Real-Time Chat with Standalone Single-File Binaries**
- Private web chat with 5-digit room PINs, instant clipboard image sharing, and zero-dependency standalone executables built with `pkg` for Windows, macOS, and Linux.
